# The `bilder` branch

This branch has **no parent commit and no source code**. It holds nothing but
the screenshots that `README.md` and `README.de.md` on `main` link to, and it is
**replaced** — not extended — every time they are remade.

That is deliberate. `CONTRIBUTING.md` on `main` says screenshots do not belong
in the history of a branch; keeping them here means `main` stays free of
binaries, and because this branch is replaced rather than added to, a clone
carries one set of pictures instead of every set there has ever been.

- How the pictures are made, what they show, what was kept out of frame and how
  they were checked for anything personal:
  [`docs/bilder/README.md` on `main`](https://github.com/ZeptronIT/ZepOS/blob/main/docs/bilder/README.md).
- Do not open a pull request against this branch. Fixes to the pictures are
  changes to the tree they were taken from.
