ZepOS-Paketquelle

Dies ist die Paketquelle von ZepOS. Sie wird von pacman gelesen, nicht von einem Browser.

Eintrag in /etc/pacman.conf

[zepos]
SigLevel = Required TrustedOnly
Server = https://zeptronit.github.io/ZepOS/$arch

Ein installiertes ZepOS hat diesen Eintrag bereits; das Paket zepos-keyring bringt den Schluessel mit.

Schluessel

Fingerabdruck:

FF2EB06C08A57FEA9E33FC46157C1725A578B80C

LeonMarzollDev (ZepOS Release) <126802872+LeonMarzollDev@users.noreply.github.com>

Der oeffentliche Schluessel liegt als zepos-repo.pub daneben. Von Hand importiert wird er so:

pacman-key --add zepos-repo.pub
pacman-key --lsign-key FF2EB06C08A57FEA9E33FC46157C1725A578B80C

Was hier liegt

manifest.txt nennt den Commit, den Arch-Stichtag und die sha256-Summe jedes Pakets. x86_64/ ist das Verzeichnis, das $arch im Server-Eintrag aufloest.
